# Deskmate beta demo

Open the demo: https://hiroshihamada.github.io/deskmate-web-beta/

Deskmate moves an avatar in time with the sound being played. Share a browser tab with a site that outputs audio, and the avatar moves with the voice. Deskmate itself does not use the microphone and keeps no record of the conversation.

## How to use

1. Use Google Chrome or Microsoft Edge on a desktop PC.
2. In another tab, open a service that outputs audio.
3. Open the demo and press "Start avatar".
4. In the sharing dialog, choose the tab that outputs the audio and turn on "Also share tab audio".
5. The avatar moves with the service's audio.

The page can be shown in English or Japanese (button in "How to start", or `?lang=en` / `?lang=ja`).
"Adjust avatar" on the left changes the camera, mouth, posture and motion; changes stay in your browser.

## Terms

This demo offers part of the features of an experimental tool for measuring how embodied AI affects people. If you would like to use the tool in experimental research, please contact the author (we are looking for collaborators).

# Deskmate β版デモ

デモを開く：https://hiroshihamada.github.io/deskmate-web-beta/

Deskmate は、再生する音に合わせてアバターを動かします。音声を出力するサイトを開いたブラウザのタブを共有すると、声に合わせてアバターが動きます。Deskmate側ではマイクを使わず、会話内容の記録も残りません。

## 使い方

1. パソコンの Google Chrome か Microsoft Edge を使います。
2. 別のタブで音声を出力するサービスを開きます。
3. デモを開き、「アバター開始」を押します。
4. 共有の画面で 音声出力元のタブを選び、「タブの音声も共有」をオンにします。
5. サービスの音声に合わせてアバターが動きます。

表示は日本語と英語を切り替えられます（「はじめに」のボタン、または `?lang=ja` / `?lang=en`）。
左の「アバター調整」で、カメラ、口元、姿勢、体の動きを変えられます。変えた値はこのブラウザに残ります。

## 利用条件

本デモは，身体化したAIがヒトに及ぼす影響を測定するための実験ツールの機能を一部抽出したものです．本ツールを用いて実験研究したい方は著者までご連絡ください（共同研究者を募集しております）．
